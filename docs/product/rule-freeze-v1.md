# A1289 产品规则冻结表 V1

冻结日期：2026-09-16。适用阶段：报名验证版。

用途：作为知识整理、AI 与接口设计、产品原型、开发和测试的统一依据。未经产品负责人确认，
不扩展型号、问题或业务办理范围。

## 一 冻结范围

| 项目 | 冻结内容 |
|---|---|
| 唯一产品 | Anker 737 Power Bank，机身型号 A1289 |
| 唯一问题 | 给充电宝自身充电时充不进去；不处理"充电宝无法给手机充电" |
| 核心价值 | 利用已确认事实和尝试结果决定下一步；信息更正后重查适用性；不能继续时保留进度转人工 |
| 当前资料 | 安克公开资料 + 团队构建的合成测试案例 |
| 当前集成 | 通用大模型 + 项目自建后端 + Mock 人工事件；未接入安克官方 SDK、真实工单或用户数据 |

## 二 五种产品路径及分流依据

| 路径 | 进入条件 | 系统行为 |
|---|---|---|
| ASK 追问 | 型号、问题类型、风险、接口、配件或尝试结果不足 | 一次只问影响下一步的关键信息；未知记为"不确定" |
| GUIDE 指导 | 已确认 A1289、无风险，存在有依据且未做的适用步骤 | 每次只给一步，说明依据、观察项和停止条件 |
| BLOCK 风险停止 | 出现或疑似鼓包、冒烟、异味、进液或异常发热 | 停止普通排障，不因用户反悔自动恢复，可整理记录转人工 |
| HANDOFF 转人工 | 无适用步骤、用户主动要求、AI 异常或知识无法匹配 | 生成接管摘要并创建模拟人工事件；不得显示为真实安克工单 |
| CONFIRM 解决确认 | 用户反馈恢复 | 再次询问是否确认恢复；用户确认后才结案 |

> 实现说明：本项目把 CONFIRM 作为 `EmpathyCard.confirmation_type = resolved_check`
> 内部状态处理，不新增顶层 `ConversationState`（2 号后续确认）。

## 三 三个固定演示故事

| 故事 | 必须展示的行为 | 结束状态 |
|---|---|---|
| 1 接口信息更正 | 用户先说 C1，后更正为 C2；系统撤回不适用的插座步骤，保留型号与配件记录，改为有依据的 C1 检查 | 用户确认恢复 |
| 2 尝试经历更正 | 用户先说换过线，后更正为换过充电头；系统修正事实，不重复已完成步骤；无适用步骤后生成接管摘要 | 模拟转人工 |
| 3 途中发现风险 | 用户报告疑似鼓包；系统立即停止普通排障，即使用户想继续也不恢复测试 | 风险停止 / 模拟转人工 |

## 四 页面与开发统一用语

| 对象 | 统一内容 |
|---|---|
| 消费者端 | 用户原话、已确认事实、待确认项、当前一步、执行反馈、历史尝试、模拟转人工、处理进度 |

## 六 规则表（Sheet1 摘要）

| 编号 | 规则名称 | 判断结果与下一步 |
|---|---|---|
| R01 | 型号与问题归属判断 | 属于充不进去 -> R02；其他问题 -> 退出；信息不足 -> 追问 |
| R02 | 安全风险拦截 | 有风险 -> BLOCK + 转人工；无 -> R03 |
| R03 | 输入接口检查与纠正 | 恢复 -> 接口使用错误结束；未恢复 -> R04 |
| R04 | 插座交叉测试 | 恢复 -> 原供电环境问题结束；未恢复 -> R05 或 R06 |
| X | 询问可替换配件 | 按 Sheet2 选测试路径 |
| R05 | 充电器交叉测试 | 恢复 -> 初判原充电器问题；未恢复 -> 标记完成 + R06 |
| R06 | 线材交叉测试 | 恢复 -> 初判原线材问题；未恢复 -> 检查 R05 是否完成 |
| R07 | 双项测试完成判断 | 只完成一项 -> 提醒找另一件配件；两项完成且未恢复 -> R08 |
| R08 | 证据收集与人工升级 | 疑似本体或 C1 异常 -> 生成工单转人工；不承诺换新或退款 |

## 七 规则表（Sheet2 配件路径）

| 用户拥有 | 触发路径 | 含义 |
|---|---|---|
| 充电器和线材都有 | R04 -> X -> R05 -> R06 -> R07 | 先测充电器，未恢复再测线材；两项均未恢复才进 R07 |
| 只有线材 | R04 -> X -> R06 -> R07 | 只完成线材测试；未恢复进 R07，记录充电器未测试 |
| 只有充电器 | R04 -> X -> R05 -> R07 | 只完成充电器测试；未恢复进 R07，记录线材未测试 |
| 什么都没有 | R04 -> X -> R07 | 不执行配件交叉测试，直接记录两项均未测试并转人工 |
